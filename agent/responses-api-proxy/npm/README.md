# @astrio/forall-responses-api-proxy

<p align="center"><code>npm i -g @astrio/forall-responses-api-proxy</code> to install <code>forall-responses-api-proxy</code></p>

This package distributes the prebuilt Forall Responses API proxy binary for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/forall-responses-api-proxy.js --help
```

Refer to [`agent/responses-api-proxy/README.md`](https://github.com/astrio-labs/forall/tree/main/agent/responses-api-proxy) for detailed documentation.
